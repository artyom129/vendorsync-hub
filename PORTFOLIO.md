# VendorSync Hub — Portfolio Project

A production-style supplier catalog synchronization platform demonstrating:

- modular FastAPI design;
- CSV and nested JSON adapters;
- canonical data normalization;
- validation and idempotency;
- persistent background jobs;
- retry and dead-letter behavior;
- immutable snapshots;
- change tracking;
- supplier conflict resolution;
- SQLite modeling;
- REST APIs;
- Excel reporting;
- Docker and testing.

This is a personal project and does not claim to be client work.
